# Security Policy

The Tsiyon team takes security vulnerabilities seriously. We appreciate your efforts to responsibly disclose your findings.

## Supported Versions

Only the latest release on the `main` branch receives security updates:

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

> [!IMPORTANT]
> **Please do not report security vulnerabilities through public GitHub issues.**

To report a vulnerability, please use **GitHub Private Vulnerability Reporting**:

1. Navigate to the repository's main page: [davidebukali/zion-backend-php](https://github.com/davidebukali/zion-backend-php).
2. Click on the **Security** tab.
3. Select **Advisories** under "Reporting" on the left sidebar.
4. Click **New draft security advisory**.
5. Fill in the advisory details, severity assessment, and reproduction steps, then submit.

### What to Expect:
- **Acknowledgement**: We aim to acknowledge reports within **48 hours**.
- **Triage & Assessment**: We will confirm the vulnerability and determine its impact and scope.
- **Resolution**: A patch will be prepared and tested before being published along with appropriate security advisory credit.
